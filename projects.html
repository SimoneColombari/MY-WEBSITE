Flipper Zero with Bruce and ESP32
An educational and diagnostic device based on ESP32, inspired by the Flipper Zero, with advanced features for networks, RF, IR, BLE and electronic debugging.
🧠 Integrated features
  • 🔹 WiFi / Networks: SSID scanner, coverage test, channel congestion, basic sniffer, ping monitor, ARP scan, uptime logger
  • 🔹 RF / NFC / RFID: Tag reading/writing/emulation, RF signal analysis
  • 🔹 Infrared: Universal remote, IR sensor testing, protocol analysis
  • 🔹 Bluetooth / BLE: BLE scanner, signal testing, beacon events, peripheral connections
  • 🔹 GPIO / Debug: Basic multimeter, continuity tester, logic oscilloscope, servo/relay/LED control, signal generator
  • 🔹 Extras: Datalogger, educational games, electronic agenda, QR Code display, Geiger counter

Meshtastic with Heltec V3
An off-grid communication system based on LoRa technology that allows creating a mesh network without internet connection, perfect for hikes and emergency situations.
📡 Project details
  • 🔹 Technology: Mesh network based on LoRa, completely off-grid
  • 🔹 Device: Heltec V3 with integrated antenna
  • 🔹 Features: Text communication, future GPS integration
  • 🔹 Autonomy: About 8 hours of continuous use with integrated battery
  • 🔹 Firmware: Latest stable version of Meshtastic
  • 🔹 Uses: Hikes, emergencies, areas without coverage
